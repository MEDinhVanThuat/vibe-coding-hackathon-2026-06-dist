# tasks/

> Ngôn ngữ: [English](README.md) | [日本語](README.ja.md) | **Tiếng Việt**

Thư mục này chứa nội dung task của hackathon:

| Khi nào | Nội dung | Cách lấy về |
|---|---|---|
| **Trước sự kiện (bây giờ)** | `user-stories.{md,ja.md,vi.md}` — đề bài | Đã có trong bản clone của bạn; có thể đọc hoặc nạp vào AI bất cứ lúc nào |
| **Mốc 0:50 trong ngày sự kiện** | `tasks/specs/` — các ví dụ spec cho task ưu tiên cao | Chạy `git pull upstream main` ở mốc 0:50 |

`tasks/user-stories.*` được cố ý phân phối trong repo trước sự kiện để bạn có thể nạp vào AI tool (Claude Code / Codex / Cursor / v.v.) từ trước. `tasks/specs/` được giữ lại đến mốc 0:50 — Phase A (0:10-0:50) được thiết kế để giải chỉ từ user story, còn Phase B (0:50-1:25) mở thêm các ví dụ spec.

> **Lưu ý**: hãy pull từ `upstream/main` (repo của ban tổ chức), không phải từ `origin` (fork của bạn). Bước 2 trong `docs/pre-event-setup.vi.md` mô tả cách thêm remote `upstream`.

Xem `README.vi.md` (cấp trên) để biết timeline đầy đủ trong ngày. Quy trình nộp bài xem `docs/submission.vi.md`.
