# tasks/

> Languages: **English** | [日本語](README.ja.md) | [Tiếng Việt](README.vi.md)

This directory contains the task content for the hackathon:

| When | What | How to get it |
|---|---|---|
| **Pre-event (now)** | `user-stories.{md,ja.md,vi.md}` — the task brief | Already in your clone; read or feed to AI any time |
| **0:50 mark of the event** | `tasks/specs/` — spec examples for the high-priority tasks | `git pull upstream main` at 0:50 |

`tasks/user-stories.*` is intentionally distributed in the pre-event repo so you can ingest it into your AI tool (Claude Code / Codex / Cursor / etc.) ahead of time. `tasks/specs/` is held back until the 0:50 mark — Phase A (0:10–0:50) is meant to be solved from user-stories alone, and Phase B (0:50–1:25) opens up the spec examples.

> **Note**: pull from `upstream/main` (the organizer repo), not from `origin` (your fork) — `docs/pre-event-setup.md` step 2 covers adding the `upstream` remote.

See `README.md` (top-level) for the full day-of timeline. `docs/submission.md` covers the PR submission flow.
