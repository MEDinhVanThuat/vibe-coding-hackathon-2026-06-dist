## 提出方法

このテンプレートを埋めたものは、**PR 本文の末尾に追記する形で必ず提出してください**。PR は組織レベル分析の主要データソースであり、振り返りはコードから推定できない情報（ツール所感・任せた境界・詰まり方）を含むため必須項目です。

**自分の母語（日本語 / 英語 / Tiếng Việt のいずれか）で書いて OK** です。書きやすい言語を優先してください。完璧でなくて OK、思い出せる範囲で具体的に書くことを優先してください。

時間内に PR を Open できなかった場合は、同じ内容を Slack DM で運営へ送ってください（フォールバック）。
