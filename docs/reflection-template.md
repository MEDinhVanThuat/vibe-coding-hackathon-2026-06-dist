**Append it to the end of your PR description as a required submission item** (see "How to submit this" below). If you couldn't open a PR, Slack DM is the fallback channel.

You do not need to be exhaustive. **Be specific about what you remember**: that is what feeds the organization-level analysis.

## How to submit this

Append this filled-out template **to the end of your PR description as a required submission item**. The PR is the primary data source for the org-level analysis, and reflection captures information that cannot be inferred from code (tool perception, where you delegated vs decided, where you got stuck), so it is required.

**Write in your native language (Japanese / English / Tiếng Việt) — pick whichever you write fastest.** Don't aim for perfection; specificity within what you can recall matters more.

If you couldn't open a PR within the time limit, send the same content to the staff via Slack DM as a fallback.
